# SmartWatch
Настольное приложение измерительной станции и веб-интерфейс для просмотра информации и работы с носимыми часами.
Моя задача заключалась в объединении оборудования и программных компонентов в работающую систему: подключении датчиков к настольному приложению, организации взаимодействия часов с веб-приложением и обмена данными между настольной и веб-частями.
Реализовал пошаговый сценарий измерений, получение и сохранение показаний, отображение результатов и статусов. Обработка данных и правила определения статусов соответствовали техническому заданию заказчика.
Технологии: C#, .NET 8, Avalonia, SQLite, React, Node.js, обмен данными по USB/UART и HTTP/JSON.
Результат: совместно с командой довели комплекс до рабочего прототипа и проверили взаимодействие с оборудованием.
